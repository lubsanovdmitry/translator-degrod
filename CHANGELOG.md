# Changelog

## 0.2.0

- Package built-in prompts and starter profiles.
- Add schema-v2 memory checkpoints and checksummed translation-hop artifacts.
- Add per-run remote request rate limiting, budgets, and normalized usage telemetry.
- Add offline `plan`, active `doctor`, and profile-aware `init` commands.
- Add optional local semantic similarity and hop-drift metrics.
- Add matrix aggregation, paired baseline deltas, and continue-on-failure mode.
- Add wheel smoke testing, GitHub Actions, stricter validation, and MIT licensing.
- Deprecate `runtime.resume` in favor of the explicit command; removal is planned for v1.0.

## 0.1.0

- Initial reproducible semantic-degradation experiment runner.
